# RANSAC mini-study v2 — starvation/mistuning vs. structural mismatch

Script: `scripts/evaluate_sparse_anchor_ransac_v2.py`
Output: `data/dfc2019/experiments/sparse_anchor_ransac_v2/`
Grid anchors for n=30/50/100 generated by re-running the unmodified Stage-1
generator (`evaluate_sparse_anchor_robust.py --strategies grid --anchors 30 50 100`)
into `data/dfc2019/experiments/sparse_anchor_robust_ext/` — same deterministic
selection logic as the existing n=10/20 anchors, just more of them. Neither
`sparse_anchor_robust/` nor `sparse_anchor_regression/` (Stage 1/2) was touched.

## Question

Stage 2 found RANSAC (sklearn defaults) did not beat OLS/Huber at n=10/20
grid anchors. Was that because RANSAC is structurally the wrong tool for this
noise, or because it was starved of data / mistuned (too few anchors for
consensus voting, default `residual_threshold` heuristic mismatched to this
problem, too few trials)?

## What was changed vs. Stage 2

1. **Anchor counts**: added grid n=30, 50, 100 alongside the existing 10, 20.
2. **`residual_threshold`**: tuned empirically instead of using sklearn's
   default (MAD of the target y). A calibration pass fit OLS on the n=20 grid
   anchors for all 50 tiles, evaluated residuals on each tile's strict
   spatial holdout, and pooled ~46.3M residuals across tiles. Pooled median
   |residual| = **2.11 m** → used as a single fixed `residual_threshold` for
   every RANSAC fit in the sweep (pooled mean |residual| was 3.24 m; p25/p75
   were 0.90 m / 4.16 m, for context on spread).
3. **`max_trials`**: raised from 100 to 5000.
4. Inlier fraction reported alongside MAE/RMSE/Pearson/Spearman, directly
   next to OLS/Huber fit on the identical anchor coordinates and eval mask.

## Read

**RANSAC still underperforms both OLS and Huber at every anchor count tested,
including n=50 and n=100** — more data and more trials do not close the gap;
if anything RANSAC's RMSE gets *worse* as n grows (4.85m → 6.02m mean RMSE
from n=10 to n=100) while OLS/Huber stay flat or improve slightly. RANSAC's
mean Pearson does rise with n (0.28 → 0.42) simply because larger inlier
consensus sets approach the OLS fit, but it never catches up, and its
count of tiles with negative Pearson (7-15) stays far above OLS/Huber's
(1-6) throughout. Inlier fraction climbs from ~0.69 to ~0.75 with more
anchors, i.e. RANSAC is finding a plausible consensus set — it isn't simply
failing to converge — it's rejecting real signal as noise, and the bias
(strict_bias_m more negative than OLS/Huber and worsening with n) shows it's
systematically dropping the anchors representing taller structures (the
inlier-set slope underestimates height at the top of the AGL range).

**Conclusion: structural mismatch, not starvation.** Giving RANSAC 5-10x more
anchors, an empirically-derived residual threshold instead of sklearn's
default, and 50x more trials does not make it competitive with plain OLS or
Huber. This confirms the earlier Stage-2 result was not an artifact of too
little data or a mistuned threshold — the DAv2-vs-AGL relationship on these
tiles is genuinely continuous, scattered noise (consistent with the rest of
this audit's findings), not a clean signal corrupted by a small fraction of
gross outliers, which is the regime RANSAC is built for.
